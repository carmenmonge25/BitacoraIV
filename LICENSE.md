# Licencias de la infraestructura:

- # PostgreSQL

PostgreSQL se utiliza bajo la Licencia PostgreSQL, esta licencia es de código abierto permisiva. Es similar a otras licencias como BSD o MIT.\[1\]


- # Apache Guacamole

Apache Guacamoles se distribuye bajo la Licencia Apache, versión 2.0. Se trata de un a licencia de software libre y código abierto que es mantenido de forma activa por la comunidad de desarrolladores.\[2\]


- # OpenSSH

OpenSSH está disponible bajo licencia de tipo BSD, la cual es una licencia permisiva que utiliza código abierto\[3\]
